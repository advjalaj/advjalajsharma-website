# advjalajsharma.in

Website of Jalaj Sharma, Advocate (Delhi). Plain static site, no build step.

- `index.html` — the whole site (styles and script inline)
- `assets/jalaj-sharma.jpg` — portrait (owned by Jalaj Sharma)
- `assets/share.jpg` — link-preview image cropped from the portrait
- `assets/favicon.svg` — original monogram

Hosted on Netlify, deployed automatically from the `main` branch. Domain: advjalajsharma.in.

Content rules: no client names or case details, no testimonials, no success claims, no "best lawyer" wording (Bar Council of India Rule 36). Only original text and the owner's own images. Fonts are Libre Caslon Text and Inter from Google Fonts (SIL Open Font License).
